# Conversor

Bienvenido a la documentación de **Conversor**, una aplicación de consola escrita en Python que convierte valores de temperatura entre distintas escalas.

## ¿Qué hace la aplicación?

Conversor permite al usuario:

- Convertir entre grados **Celsius**, **Fahrenheit** y **Kelvin**.
- Introducir el valor desde la terminal y obtener el resultado al instante.

## ¿Para quién es?

Está pensada como proyecto de prácticas para aprender a programar en Python y a documentar un proyecto con **MkDocs**.
